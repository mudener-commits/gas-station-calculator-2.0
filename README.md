# 加油（加气）站利润计算器小程序版

## 项目备注

这是一个面向加油站、加气站经营者的本地测算小程序 2.0 独立版本。项目把“日常经营能不能赚钱”“这个投资方案值不值得做”“每天至少要卖多少”拆成三个并列入口，让经营数据、投资条件和销量目标能够分别看清，也能相互校验。

- **利润计算器**：根据销量、售价、采购价与日常费用，测算租金前经营 EBITDA，先判断站点的基础经营能力。
- **投资回报计算器**：在经营基础上加入租金、固定资产、流动资金、贷款和合作条件，查看年度净利润、年度净现金回笼、NPV、回收期与 IRR。
- **盈亏平衡销量计算器**：分别倒推财务盈亏平衡销量和投资回报平衡销量。前者以经营期年均净利润为 0 为目标，包含折旧；后者以我方 NPV 为 0 为目标，考虑投入、收付款时点和期望年回报率。

项目按“先测算、再比较、最后决策”的顺序使用更合适：利润计算器用于估算经营基础，投资回报计算器用于比较不同租赁和融资方案，盈亏平衡销量计算器用于检验销量目标是否可实现。油品结果以升/日、LNG 以公斤/日分别展示，不把不同物理单位直接相加。

所有填写数据和方案默认保存在当前微信设备本地；只有用户主动生成并分享的报告图片会离开设备。项目提供的是经营比较和项目初筛工具，不能替代财务报表、税务申报、合同审查、资金计划或正式投资决策。租金、税费、资产投入和融资条件应以合同、票据及实际资金安排为准。

`v2.0.0` 是本仓库的首个独立版本，包含 2.0 的完整源码、测试与测算口径说明；旧版 1.4.1 保留在单独仓库中，不与本版本混合维护。

流动资金：新方案默认 500000 元，可修改；计入期初投入并在预测期末全额收回，不折旧、不计费用或利润，首期预付租金另计。我方回收流动资金，融资不影响项目无融资口径回报。旧草稿/方案缺少该字段时保留原口径 0 元，不修改原存档。单月现金净流出不等于账户资金不足，本模型不模拟资金留存、实际账户余额或分红安排。IRR 仍保留多次变号的保守判定。

投资报告指标（2026-09-25）：主指标改为年均净利润，增加项目/我方“年度净现金回笼（年均）”及全周期累计净现金收益；NPV、回收期保留，IRR 放在辅助位置。年折现率改称“年折现率（期望年回报率）”，两版报告均显示采用值和 NPV 解释。计算关系见 [投资指标口径说明](投资指标口径说明.md)。

租赁模式更新：原“税前利润分成”改称“动态租金（业主分红）”，在租金费用及报告中列示，只扣一次；取消双方出资合作，保留固定管理费。旧双方出资方案须重新选择方式，原始数据保留，不自动转换租金比例；历史报告标明旧口径。

当前本地版本：`2.0.0`。旧版公式修复版独立保存在相邻目录 `wechat-miniprogram-1.4.1/`。

盈亏平衡销量入口已从投资回报页移至首页。独立草稿会自动保存，首次使用会复制原内嵌倒推草稿；之后编辑两个计算器互不覆盖。年度修正只保留一份共用模板，须显式填入。

独立的盈亏平衡销量计算器：分别按经营期年均净利润为 0（含折旧）和我方 NPV 为 0（按期望年回报率）求解，在独立页面填写租金、投入、贷款与年度修正，共用财务公式。单位经营费用默认汽油 0.3 元/升、柴油 0.1 元/升、LNG 0.1 元/公斤。年度修正新建默认全为 0，可独立保存唯一设置并覆盖、手动填入或全部归零。具体假设见 [盈亏平衡销量口径](盈亏平衡销量口径.md)。

本次 85 项测试通过，包含官方 WXML 编译；已检查 320、375、430 像素宽度的离线排版。真机显示与操作仍需验收。

盈亏平衡销量计算后可查看报告，生成简要版或完整版分享图片，支持预览、保存相册和微信图片分享。报告包含两类销量、油气配比、毛利、单位费用、财务条件与口径说明；完整版另列资产折旧和逐年修正。结果使用计算时快照，修改输入后须重新计算。

## 2.0.0 使用方式

首页提供三个并列入口：“利润计算器”“投资回报计算器”“盈亏平衡销量计算器”。利润只测算租金前经营 EBITDA（息税折旧摊销前利润）；年度净利润、租赁、资产、合作、贷款及投资回报在投资页计算。

支持选择最近 5 条或指定历史报告，手动填写经营基础，按年修订 EBITDA，并生成含中文说明的完整图片报告。预测默认 10 年、折现率默认 7%。全部选择项直接展开，报告改为单张完整长图，上下查看、整张保存或分享。

2026-09-24 调整：商业保险默认 3500 元/年、土地使用税默认 10000 元/年；升油费用以红色显示并附每吨费用，液化天然气按每公斤显示，不计算吨均收益。增加长租长付（支持每次预付 2、3、5 年及自定义年数），业主动态租金比例默认 50%，贷款默认按期还息、到期还本，也可选等额本息；折旧年限默认等于且不超过经营年限。年度修订支持每次增减 1 个百分点。

报告包含小程序及公众号 Logo、Slogan“在这里，读懂中国加油站。”以及欢迎词。投资报告逐年部分采用六列核心指标表：年份、经营收益、年度净利润、项目现金流、我方股东现金流、我方累计现金流，统一以万元展示，保留全部年份和中文术语；长周期报告会按画布限制等比例缩放，设备导出失败时自动尝试兼容尺寸，不截断内容。

详细变更与测算口径见 [CHANGELOG.md](CHANGELOG.md)。本目录运行 `npm test` 验证公式与页面逻辑；测试和离线预览脚本不会打包进小程序。

利润页价格统一按含税、带票填写。旧不含税报价恢复时自动换算，不修改原存档；报告以“经营收支概览”展示销售额（含税）、采购成本（含税）、日常经营费用、经营税费、租金前经营收益，隐藏销项、进项及净额收支等过程值。房产税和土地使用税归入经营税费，不在日常费用里重复展示。内部计算不变、不重复扣增值税，经营收益不等同于实际现金净流入。测算假设油气采购进项可抵扣，未模拟库存、期初留抵、抵扣时点及其他经营费用进项税，不等于实际税务申报。

开发范围：仅 2.0 大版本。用户已确认 1.4.1 提交使用；未再次明确要求之前，不修改、不重新打包、不上传覆盖 1.4.1。

图片分享分为两个独立入口：简要版展示核心指标、经营概览/投资条件，完整版保留所有明细与逐年表格；两版的测算口径和术语说明共用同一套精简文案，详细假设在独立说明页查阅。两种图片分别生成、预览、保存、分享，不互相覆盖；均保留双 Logo、公众号 Slogan 和欢迎词。原生微信分享及相册权限需真机验收。

以下为历史版本说明；与 2.0.0 不一致的描述以本节及 CHANGELOG 为准。2.0.0 尚未上传或发布。真实手机的长图保存、相册权限和微信分享仍待验收。

## 1.4.0 版本备注

- 顶部文案更新为“本地计算，数据安全”。
- 明确从事成品油销售的加油站统一按增值税一般纳税人口径测算；保留“小型微利企业优惠测算”，仅作为企业所得税优惠估算。
- 新增“我的默认数据”：可保存除销量外的开关、模式、价格、费用、税率和分摊系数，并支持填入和二次确认清除。
- 人员成本新增独立“站长月工资”；社保开关默认关闭，开启后按普通员工与站长工资总额的 32% 估算企业承担部分。
- 新增本机历史报告数据：点击“保存填写数据”后仅保存输入数据（含销量）、名称（可为空）、月/年口径和生成时间，不保存图片或计算结果；可恢复到首页后按当前日期重新导出图片，支持单条删除和全部清空，最多保留 100 份。

## 1.3.4 版本备注

更新“转发给朋友/群聊”的 5:4 小程序展示卡片，突出加油（加气）站利润计算器、纳税成本、毛利计算和盈亏评估等核心功能；分享到朋友圈继续使用小程序 Logo。

## 1.3.3 版本备注

本版将小程序调整为纯粹的加油（加气）站利润计算器，删除“给作者留言”、油站资产流转登记及登记记录功能，不再收集或保存用户联系方式和油站流转信息。保留利润测算、完整报告、公式说明及图片分享功能；转发给朋友使用 5:4 展示卡片，分享到朋友圈使用小程序 Logo。新版首次打开时会自动清除旧版本留在本机的留言和登记数据。

## 使用方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`wechat-miniprogram`。
4. AppID 填写你已经认证通过的小程序 AppID。
5. 打开后点击“编译”，即可预览。
